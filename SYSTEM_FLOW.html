AWiSBA System Flow

Database Flow for Field Monitoring and Smart Acoustic Analysis

เอกสารนี้แยก flow ของระบบออกเป็น 2 ส่วนชัดเจน: ข้อมูลจาก Field Device สำหรับ Dashboard และ Smart Acoustic Analysis สำหรับการ upload ไฟล์เสียง วิเคราะห์เฉพาะครั้งนั้น

Field Device Monitoring Flow

อุปกรณ์ส่ง audio chunk ไม่เกิน 5 วินาทีเฉพาะตอนมีเสียง ถ้าไม่ส่ง ระบบถือว่าไม่มี acoustic event จากนั้นรวมผลเป็นช่วงเวลาเพื่อแสดงใน Dashboard

Device Dashboard 
flowchart TD
  A["Field Device in forest"] --> B["Detect acoustic event"]
  B --> C{"มีเสียงหรือไม่?"}

  C -- "ไม่มีเสียง" --> D["ไม่ส่ง audio chunk"]
  D --> E["No acoustic event"]

  C -- "มีเสียง" --> F["Record audio chunk up to 5 seconds"]
  F --> G["Send audio chunk + metadata"]
  G --> H["Supabase Storage stores audio file"]
  G --> I["audio_uploads"]

  A --> J["Send device health data"]
  J --> K["device_health_logs"]

  I --> L["Model API inference"]
  L --> M["inference_runs"]
  M --> N["device_sound_events"]

  N --> O{"Unknown or low confidence?"}
  O -- "Yes" --> P["unknown_reviews"]
  O -- "No" --> Q["Accepted event"]

  N --> R["Aggregate many chunks by time period"]
  R --> S["acoustic_indicators"]
  R --> T["Update latest summary in devices"]

  K --> U["Device Dashboard"]
  S --> U
  T --> U
  P --> U

Smart Acoustic Analysis Flow

User upload ไฟล์เสียงเอง ให้ model วิเคราะห์ แล้วแสดงผลแบบช่วงวินาที เฉพาะใน feature นี้ ไม่อัปเดต Device Dashboard

Standalone Analysis 
flowchart TD
  A["User uploads audio file"] --> B["Smart Acoustic Analysis"]
  B --> C["Send file to Model API"]
  C --> D["Model analyzes full audio file"]
  D --> E["analysis_uploads"]
  E --> F["analysis_runs"]
  F --> G["analysis_segments"]
  G --> H["Display per-second result"]
  H --> I["End"]

  I -. "ไม่เชื่อมกับ" .-> J["Device Dashboard"]

ตารางกลุ่มนี้ใช้กับอุปกรณ์จริงและหน้า Dashboard เท่านั้น

Field Device Tables 
flowchart TD
  A["devices"] --> B["audio_uploads"]
  B --> C["inference_runs"]
  C --> D["device_sound_events"]
  D --> E["unknown_reviews"]

  A --> F["device_health_logs"]
  A --> G["acoustic_indicators"]

  D --> G
  F --> H["Device Dashboard"]
  G --> H
  A --> H

devices

หน้าที่: เก็บข้อมูลอุปกรณ์ เช่น ชื่อ, location, รูป, status, battery, storage, signal และ summary ล่าสุด

audio_uploads

หน้าที่: เก็บ metadata ของ audio chunk จากอุปกรณ์ ความยาวไม่เกิน 5 วินาที เฉพาะตอนมีเสียง

inference_runs

หน้าที่: เก็บประวัติการนำ audio chunk เข้า model เช่น model version, status, confidence สูงสุด

device_sound_events

หน้าที่: เก็บผล model ของ chunk นั้น เช่น sound groups, dominant sound group, confidence, noise level

unknown_reviews

หน้าที่: เก็บ event ที่ต้องให้คนตรวจ เช่น Unknown หรือ confidence ต่ำ

device_health_logs

หน้าที่: เก็บสุขภาพอุปกรณ์ตามเวลา เช่น battery, signal, storage, pending uploads

acoustic_indicators

หน้าที่: เก็บ summary เป็นช่วงเวลา เช่น detected sound groups, average confidence, noise level, peak activity window

ตารางกลุ่มนี้ใช้กับไฟล์ที่ user upload เอง วิเคราะห์แล้วจบ ไม่เกี่ยวกับอุปกรณ์จริง

Analysis Tables 
flowchart TD
  A["analysis_uploads"] --> B["analysis_runs"]
  B --> C["analysis_segments"]
  C --> D["Smart Acoustic Analysis Result UI"]

analysis_uploads

หน้าที่: เก็บไฟล์เสียงที่ user upload เองในหน้า Smart Acoustic Analysis

analysis_runs

หน้าที่: เก็บรอบการวิเคราะห์ไฟล์นั้นด้วย model เช่น status, model version, dominant group

analysis_segments

หน้าที่: เก็บผลแบบช่วงวินาที เช่น 0-5 sec = Bird, 5-10 sec = Frog ใช้แสดงเฉพาะ feature นี้

Scientific note: Dashboard reports detected sound groups, acoustic activity, confidence, disturbance context, and preliminary acoustic indicators. It does not report animal population counts.
